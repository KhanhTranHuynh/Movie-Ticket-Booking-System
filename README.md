# Movie Ticket Booking System

A full-stack movie ticket booking website built with ReactJS, Node.js, and MySQL, featuring online ticket booking, seat selection, ZaloPay payment, and real-time chat.

## Tech Stack
- **Frontend:** ReactJS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Real-time Communication:** Socket.IO
- **Payment Gateway:** ZaloPay

## Features
- User authentication
- Movie and showtime management
- Seat selection and ticket booking
- Online payment via ZaloPay
- Booking history management
- Admin dashboard
- Real-time chat
